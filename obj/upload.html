obj/assets 파일 현황

GitHub Pages는 정적 호스팅만 제공하므로, 브라우저에서 서버로 파일을 “업로드”할 수는 없습니다. 파일은 git으로 obj/assets/에 추가한 뒤 푸시하고, 아래 catalog.json의 allFiles와 models를 함께 갱신하세요.

← 3D 뷰어
요약: 저장소에 커밋된 파일 목록은 catalog.json 또는 (선택) GitHub API로 표시합니다. site-config.js에서 GitHub 조회를 켜면 public 저장소의 해당 경로 파일을 자동으로 나열할 수 있습니다.

새 모델을 사이트에 반영하는 절차

  1. 모델·텍스처 파일을 obj/assets/에 복사합니다.
  2. obj/catalog.json의 allFiles에 파일명을 추가합니다.
  3. 뷰어 탭에 넣으려면 models 배열에 id, label, type, path (및 OBJ일 때 mtl)을 추가합니다.
  4. 커밋 후 푸시하면 GitHub Pages에 반영됩니다.

로컬에서만 GLB를 바로 보고 싶다면 뷰어의「로컬 GLB 불러오기」를 사용하세요.
